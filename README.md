# Recruitment Landing Page

Современный адаптивный сайт для подбора персонала, созданный по макету Figma с использованием HTML и Tailwind CSS. Проект выполнен в современном минималистичном стиле с акцентом на чистый UI/UX дизайн, responsive layout и удобный пользовательский интерфейс.
